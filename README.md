# Animus ⛩️
**Discover your next obsession.**

Animus is a responsive web application designed for exploring anime. Powered by the real-time Jikan API (MyAnimeList), it allows users to search for titles, filter by format, and sort by rankings in a premium, streaming-style dark mode interface.

## ✨ Features
* **Smart Search:** Find any anime by title with real-time data fetching.
* **Custom Sorting & Filtering:** Combine search queries with filters (TV Shows, Movies) and sorting (Highest Rated, Ranking, Episode Count) using custom-built dropdown modals.
* **Fully Responsive:** A sleek CSS grid layout that automatically adapts to desktop, tablet, and mobile screens.
* **Connected Navigation:** Search directly from the home page and seamlessly route to a fully populated results dashboard.
* **Interactive UI:** Clickable poster cards that link directly to MyAnimeList, complete with loading spinners and custom error states.

## 🛠️ Built With
* **HTML5 & CSS3** (Custom Dark-Mode UI, Flexbox, CSS Grid)
* **Vanilla JavaScript** (ES6+, DOM Manipulation)
* **Jikan API** (RESTful data fetching)
